# Arkham power for Kiro

Connects Kiro to Arkham's hosted MCP server at `https://mcp.arkm.com/mcp` for on-chain intelligence: wallet and entity attribution, balances, transfers, token flows, risk scores, HyperCore positions and Polymarket data. You sign in with your Arkham account; calls use Arkham API credits.

- Setup and documentation: [MCP Server guide](https://arkm.com/api/docs) and the [repository README](../README.md)
- Privacy policy: https://info.arkm.com/privacy-policy
- Terms: https://arkm.com/api-terms-of-service
- Support: api@arkm.com
